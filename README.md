# 정보보안기사 필기 대비

정보보안기사 필기 요약과 객관식 문제 풀이 사이트의 GitHub Pages 배포용 저장소입니다.

## GitHub Pages 설정

1. 이 저장소의 파일과 `docs` 폴더를 GitHub에 업로드합니다.
2. GitHub 저장소에서 `Settings` → `Pages`로 이동합니다.
3. `Build and deployment`를 `Deploy from a branch`로 선택합니다.
4. Branch는 `main`, 폴더는 `/docs`를 선택한 뒤 저장합니다.

실제 사이트 파일은 모두 `docs` 폴더 안에 있으며, GitHub Pages는 `docs/index.html`을 시작 화면으로 사용합니다.

## 현재 포함 기능

- PART 1~7, SECTION 01~43 요약
- 보통 난이도 객관식 문제 563문항
- 문제 검색·채점·저장·즐겨찾기·초기화
- SECTION별 마지막 문제 복원과 메모장
- 맞춘 문제·틀린 문제 수 표시
- PIP 문제창과 PART·SECTION 계층 목차
- 라이트·다크 모드와 모바일 레이아웃
